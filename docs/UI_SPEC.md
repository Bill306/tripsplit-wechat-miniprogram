# 喵喵旅账 MVP UI 规范

日期：2026-09-21
状态：Approved for implementation

## 1. 视觉方向

主题是“旅行手账 + 清晰票据”：温暖米白底、森林绿主色、珊瑚橙操作强调，用精简的标签、虚线和数字排版建立“可核对”感。不使用泛用紫色渐变或大量悬浮卡片。

## 4. 交互原则

- 主操作固定在底部安全区上方，最小点按高度 88rpx。
- 账单金额是首个焦点，键盘弹出后仍能见到提交区。
- 可恢复错误不离开当前表单，输入和草稿不丢失。
- 数据刷新时保留旧内容并显示轻量加载态，避免整页闪白。
- 动效只用于状态过渡：卡片入场、180ms 按压、结算状态变化；不做装饰性循环动画。
- 空状态提供一个明确的下一步，不只显示“暂无数据”。

## 5. 内容与无障碍

- 不单独依赖红/绿表达应收应付，同时显示文字与正负号。
- 数字默认右对齐，重要金额使用千分位。
- 加载、失败、草稿未同步、演示模式都有文字标识。
- 触摸区域不小于 80rpx × 80rpx，正文不小于 28rpx。

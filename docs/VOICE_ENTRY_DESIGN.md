# 语音记账（首版设计）

## 交互

- 记账页增加「按住说话」入口，最多 30 秒；松开识别，上滑取消。键盘输入同一句话作为无麦克风/识别失败时的备用入口。
- 示例：「今天中午吃饭花了三千日元」→ 3000 JPY / 餐饮 / 今天 / 原句备注。
- 识别结果先显示在可编辑文本框。点击「填入账单」才替换表单；有旧内容时二次确认。仍需原来的「确认记账」才能写入账本。
- 未明确币种、多金额、退款/负数、区间或模糊金额不自动填金额。提示具体问题，避免猜测。付款人和分摊人不从首版语音中推断，保留表单选择并提醒核对。
- 仅确定识别今天/昨天/前天；其他日期表达提示在表单选择，不伪造日期。
- 外币填入后沿用已验收的换算规则；重新请求匹配币种与消费日的报价，不自行估算汇率。

## 技术与隐私

- 首选微信团队 WechatSI 插件的语音转文字接口；添加前取得项目所有者确认，并核实该 AppID 可用的插件版本。未启用时不向 app.json 添加无权限插件依赖，避免破坏整个小程序编译。
- 录音仅在用户主动操作并允许麦克风后开始，向微信插件传输录音用于转写。应用不主动上传到自己的云存储，不保存原录音、不打印识别原文日志。服务商处理规则以其隐私条款为准，不承诺服务商零留存。
- 识别文本在本地解析为结构化草稿；不调用额外大模型服务，不上传完整历史账本。只有用户确认后的普通账单按现有流程存储。
- 录音取消、切到后台、页面卸载后忽略结果；错误和超时回到可重试状态。不支持服务时明确告知，保留手动输入。
- 独立解析模块用确定性规则识别首版常见中文金额与已支持币种。多笔连续记账、复杂参与人推断及方言准确率不纳入首版承诺。

## 验收

- 覆盖中文数词、阿拉伯数字、零小数币种、货币别名、千位分隔符、日期边界。
- 多金额/退款/模糊金额不能默默作为支出写入；无币种不自动猜人民币。
- 不同语音结果不能覆盖正在提交中的账单；取消/退出后的延迟回调无效。
- 保留原手动、多币种、权限、结算回归测试。
- 插件添加、隐私声明、麦克风授权及真实手机录音必须单独验证，不能以解析单测代替。

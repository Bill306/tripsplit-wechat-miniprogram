# 登录页与首页界面

版本：2026.10.28.1

## 页面与素材

- 登录及个人资料页面采用猫咪旅行插画、奶油色纸张表单、松绿色按钮和猫爪图形。
- 首页采用双猫旅行插画、纸张行程卡片，以及绿色创建按钮和黄色加入按钮。
- 按钮具有描边、圆角、按压反馈和加载状态。行程卡片显示云端成员、消费总额、应收或应付金额。
- 微信头像选择使用 `open-type="chooseAvatar"`，昵称输入使用 `type="nickname"`。
- 两页共享 `styles/sketch.wxss` 中的颜色、纸张和按钮样式。

新增插画由 GPT Image 根据用户确认的猫咪旅行风格生成。制作要求为成熟的手绘水彩风格，使用奶油色、松绿色与蜂蜜黄色，并为页面文字留出空间。
